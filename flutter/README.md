# LGS 2027 Arena — Flutter V0.1

Flutter tabanlı gerçek Android/iOS uygulama geliştirmesinin ilk dalıdır.

## İlk omurga
- Inspired from Zeus / LGS 2027 Arena kapağı
- 13 Haziran 2027 geri sayımı
- Arena ana ekranı
- Zeus ekranı
- Fen, Matematik, Türkçe, İnkılap, Din
- 150 demo soru
- 30 Akıllı Not
- tekrar etmeyen soru seçimi için question_id geçmişi
- ipucu, çözüm yolu ve Zeus desteği
- denemede anlık doğru/yanlış göstermeyen akış
- HMGS ile aynı free/premium sonuç-reklam mantığına uygun yapı
- Türkiye ve il sıralaması için backend'e hazır ekran
- ana sayfalarda aşağı kaydırma gerektirmeyen viewport tasarımı

Tam V0.1 kaynak paketi geliştirme sırasında oluşturulmuştur. Sonraki adım bu dalda kaynak dosyalarını modüler Flutter yapısına taşıyarak Android/iOS build almaktır.
